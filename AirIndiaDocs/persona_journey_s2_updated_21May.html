Draft Register Loop Note: Both Draft 1 and Draft 2 validation runs are currently manual — PS sends Excel register via email to AI Payroll HRSS team; HRSS reviews and sends corrections back via email. No system-based validation tool exists. This is a HIGH AUTOMATION OPPORTUNITY — affects all components across all 3 stages. · Bank File generation (PS → Bank SFTP) is semi-automated: PS generates the file but manual approval/release is required before SFTP transfer.
Stage 2 Key Notes (Component View):  ·  Automated (M1+M7): 28 comps (15.2%) — SF EC → PS, zero manual touch; lowest risk.  ·  Semi-auto (M2 FBP): 19 comps (10.3%) — system-driven with Car Lease Excel override residual.  ·  Manual — highest risk: Flying Allowances M12+M20 (19 comps, 10.3%) — Pilots & Cabin Crew, high salary, CAE→Excel chain, no direct PS feed = HIGHEST LEAKAGE RISK.  ·  3rd Party Deductions M16 (12 comps) — legacy employee contracts, external stakeholders (LIC, Co-op, Trust), no system trail = HIGH AUDIT RISK.  ·  Draft Register Validation (×2): common to all PS rows; currently fully manual Excel email loop — affects all 184 active components.
